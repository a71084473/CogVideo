適合什麼階段的長輩使用?

輕度到中度認知退化的長輩最能享受完整流程;重度長輩可由照護者代為輸入故事,一起看放映、一起指認畫面元件。所有互動都沒有時間壓力、沒有失敗懲罰。

為什麼畫面裡沒有人物?

這是刻意的設計。AI 畫的臉孔對失智長輩可能造成混淆與不安(「這是誰?」),只用背景與物件敘事,長輩會自然把自己與家人放回場景,回憶反而更鮮活。

需要安裝軟體或建立帳號嗎?

不用安裝,開啟瀏覽器就能使用,支援電腦與平板。體驗版無需註冊;家庭版與機構版註冊後即可同步保存作品。

長輩的故事會被拿去做什麼?

故事屬於您的家庭。內容僅用於為您生成分鏡與插圖,不會用於廣告或訓練模型;機構版提供資料在地保存選項,符合個資保護規範。

機構要如何導入?

選擇機構版後,我們提供一次線上導入培訓、活動帶領手冊與前三個月的專人陪跑,協助治療師把拾光分鏡編入懷舊治療與認知刺激課表。
