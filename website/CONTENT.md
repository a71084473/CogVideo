# 內容填寫清單 CONTENT.md

本網站目前為**框架版**：版型、設計系統、互動與無障礙功能皆已完成，
所有文字為結構性佔位內容，須以 PDF 中的實際資料替換。

## 怎麼填

1. 在瀏覽器開啟任一頁面，按 **Alt + Shift + T** 開啟「內容檢查模式」，所有待填處會以黃底標示。
2. 依下表在 HTML 中搜尋 `data-tbd="標籤名"`，替換標籤內的文字。
3. 替換完成後，移除該元素的 `class="tbd"` 與 `data-tbd="..."` 屬性。
4. 全部完成後，搜尋整個 `website/` 目錄確認已無 `data-tbd` 殘留。

```bash
grep -rn 'data-tbd' website/   # 應無輸出
```

## 撰寫時的三個紅線

這是失智症相關的健康類產品網站，內容錯誤會造成實際傷害，也可能觸及廣告法規：

- **不得宣稱療效**：不寫「改善記憶」「延緩退化」「治療失智」。若非醫療器材，不得使用醫療器材用語。
- **引用須真實可查**：所有文獻、數據、研究出處必須是實際存在且可驗證的來源，切勿為了版面完整而填入虛構引用。
- **職銜須經授權**：團隊成員姓名、職稱、任職機構須取得當事人同意後才可刊登。
