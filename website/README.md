# 憶徑 Mnemos — 高齡失智照護產品網站

主打「專業知識」定位的靜態網站：以臨床評估分期、文獻依據與跨專業審查作為核心敘事，
而非一般高齡產品常見的情感訴求。

> **目前狀態：框架版。** 設計系統、版型、互動與無障礙功能已完成；
> 文字為結構性佔位內容，待以 PDF 中的實際資料替換。填寫方式見 [`CONTENT.md`](CONTENT.md)。

## 檔案結構

```
website/
├── index.html          # 首頁（首屏／專業依據／照護框架／產品／分期選配／團隊／知識庫／FAQ／諮詢）
├── knowledge.html      # 照護知識庫列表
├── article.html        # 文章頁模板（每篇文章複製另存）
├── CONTENT.md          # 待填內容清單（146 處，自 HTML 自動擷取）
└── assets/
    ├── css/style.css   # 設計代幣 + 全站樣式
    ├── js/main.js      # 無障礙偏好、導覽、表單驗證、進場動畫
    └── img/            # 產品與團隊圖片（待放入）
```

## 本機預覽

無建置流程，直接開檔即可；若要測試相對路徑，可起一個靜態伺服器：

```bash
cd website && python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 內容架構與「專業」的呈現方式

網站的說服邏輯是「把推導過程攤開」，而非堆砌形容詞：

| 區塊 | 承擔的說服工作 |
|---|---|
| 專業依據 `#evidence` | 三段式方法論：標準化評估 → 文獻介入原則 → 實際場域驗證，各附引用欄位 |
| 照護框架 `#framework` | 認知功能／行為精神症狀／日常生活功能／照顧者負擔四面向，解釋產品線為何這樣分 |
| 分期選配 `#matching` | CDR 分期對照表，把「這產品給誰用」講成臨床語言而非年齡 |
| 專業團隊 `#team` | 跨專業審查（醫療／治療／照護三種眼光） |
| 知識庫 | 每篇標示撰稿者、審閱者、更新日期與參考資料 |

## 設計系統

| 項目 | 值 |
|---|---|
| 標題字體 | Noto Serif TC 600/700（學術、權威感） |
| 內文字體 | Noto Sans TC 400/500/700 |
| 內文基準 | 18px / 行高 1.8（高齡友善，非 16px） |
| 主色 | 深青 `#0F5C6E`（醫療信任感） |
| 輔色 | 暖赭 `#A8571A`（重點與引用標示） |
| 反白區塊前景 | `--on-brand` / `--on-brand-500` / `--on-accent` |
| 間距 | 8pt 節奏，`--sp-1` ～ `--sp-7` |
| 斷點 | 640 / 768 / 900 / 1024px |

顏色皆以 CSS 變數定義於 `:root`，深色模式使用降飽和的色調變體（非反轉）。

反白區塊（工具列、CTA 帶）與主色按鈕的前景色一律走 `--on-brand` / `--on-brand-500` /
`--on-accent` 代幣，不寫死 `#fff`——否則深色模式下主色轉為亮青時會出現白字白底。

高對比模式共有四種組合（淺／深 × 系統偏好／明確選擇），**每個色盤都完整定義所有代幣**。
若只覆寫部分代幣，深色系統偏好下切換高對比會殘留深色底配深色字。新增代幣時，
四個高對比區塊都要補上。

## 無障礙

針對高齡與低視力使用者的實作：

- **字級調整器**（標準／大／特大，1×–1.3×）與**高對比模式**、**深色模式**，選擇存於 `localStorage`
- 內文基準 18px、行高 1.8，字級縮放以 `--scale` 變數作用於 `html` 的 `font-size`，全站等比放大不破版
- 所有可點擊元素 ≥ 48px（主要按鈕 52–60px）
- 跳至主要內容連結、可見的 focus ring（3px）、鍵盤可完整操作
- 表單：可見標籤、必填標示、`blur` 時才驗證、錯誤訊息置於欄位下方並用 `role="alert"`、送出失敗自動聚焦第一個錯誤欄位
- `prefers-reduced-motion` 下停用所有動畫
- 語意標籤、`aria-current` 標示所在章節、表格使用 `scope` 屬性
- 無 JavaScript 時內容仍完整可讀

## 已驗證項目

以 Chromium 實測（腳本見 commit 說明），全數通過：

- **對比度**：`index` / `knowledge` / `article` 三頁 × 淺色、深色、淺色高對比、深色高對比四種組合，
  所有文字皆達 WCAG AA（一般文字 4.5:1、大字 3:1），含 alpha 合成後的實際算繪色
- **功能**：字級調整器、高對比、深色模式、偏好持久化、表單驗證（空白／格式錯誤／正確）、
  錯誤欄位自動聚焦、行動版選單開關與 Esc 關閉
- **版面**：375 / 390 / 1280 / 1440px 無水平捲動
- **結構**：HTML 標籤配對、無重複 id、每頁單一 `h1`、內部錨點連結有效
- **無 JS 降級**：進場動畫的初始隱藏狀態以 `.js` 類別把關，停用 JS 時內容完整可見；
  另有 1.5 秒保險機制，確保觀察器未觸發時內容不會卡在隱藏狀態

本站為失智症相關產品網站，撰寫內容時必須遵守：

1. **不得宣稱療效** — 若產品非醫療器材，不得宣稱可治療、延緩或改善失智症病程。頁面已內建多處免責聲明，請勿移除。
2. **引用須真實可查** — 文獻、數據、研究出處必須實際存在，不得為版面完整而虛構。
3. **職銜須經授權** — 團隊成員姓名與職稱須取得當事人同意。
4. **個資保護** — 諮詢表單蒐集姓名、電話與健康狀況描述，屬個人資料；後端須為 HTTPS，並依個人資料保護法履行告知義務。
