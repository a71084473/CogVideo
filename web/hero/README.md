# 首頁 Hero 背景影片

把一段原始影片（例如 Facebook 上下載的影片）轉成適合網站首頁的「高級設備感」背景影片。

## 使用方式

```bash
cd web/hero
./make_hero.sh 原始影片.mp4 media 3 12   # 從第 3 秒開始取 12 秒
```

接著打開 `index.html` 預覽，把文案、品牌名稱換成你的內容。

## 處理內容
- **調色**：壓暗中間調、提高對比、降低飽和度、暗部冷調亮部暖調、S 曲線、暗角、細顆粒 → 沉穩的精品科技感
- **畫質**：降噪 + 輕度銳化，lanczos 縮放，固定 30fps，去除音軌
- **輸出**：1080p / 720p 各一份 AV1 WebM + H.264 MP4，外加 WebP / JPG 海報圖
- **循環**：頭尾 0.8 秒淡入淡出，loop 時不跳接

## 頁面效能與體驗
- 先顯示海報圖，影片可順暢播放才淡入（帶輕微推鏡效果）
- 手機自動載 720p；省流量模式、減少動態設定下不播放
- 捲出畫面自動暫停；提供暫停鍵（無障礙需求）

## 建議
- 選 8–15 秒、鏡頭穩定、有緩慢移動（滑軌/推軌）的片段最有質感
- 建議 1080p 檔案控制在 3–5MB 以內；若太大可把 `crf` 調高（MP4 23→26，AV1 36→40）

## 本次成品（智慧觸控螢幕展示影片）
```bash
CRF_MP4=25 SPEED=0.5 ./make_hero.sh 原始影片.mp4 media 0 3.6
```
- 只取前 3.6 秒：三台設備同框、畫面最清晰；後段鏡頭貼太近且有動態模糊
- 防手震 + 0.5 倍慢動作補幀，像滑軌運鏡；正放 + 倒放做成 14.3 秒無縫循環
- 明亮產品攝影色調（預設 STYLE=bright）：修正燈泡黃光、整體提亮、黑位保留，白色機身乾淨通透；`STYLE=dark` 可切回暗調精品版
- `photos/` 內附 3 張同色調的產品靜態照
