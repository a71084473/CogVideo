# 合拍 PawMatch 功能測試案例集
### 寵物線上認養與媒合成功情境｜B2C 微服務 Web 應用

> **角色**:資深 QA 工程師視角。**主要使用者**:四場中途訪談推導的三類認養人——P1 怕被審的新手(45%)、P2 找共感的經驗者(30%)、P3 重隱私的抗拒者(25%);次要使用者:中途(供給端)。
> **範圍**:正常流程(Happy Path)+ 高風險異常場景(驗證錯誤、會話處理、跨服務資料完整性)。
> **優先順序**:P0 = 阻斷性(核心轉換/資料安全)、P1 = 高、P2 = 中。

---

## 一、假設的微服務架構(測試邊界)

| 服務 | 職責 |
|---|---|
| `auth-svc` | 註冊/登入、會話、A/B 分組指派 |
| `quiz-svc` | 生活樣態測驗、配對演算法 |
| `catalog-svc` | 貓咪檔案、健康護照、上下架狀態 |
| `intent-svc` | 認養意向(草稿/送出/三態標記)、媒合狀態機(相識→見面→試相處→承諾) |
| `messaging-svc` | 認養人↔中途訊息、系統轉介通知 |
| `report-svc` | 曬貓回報、相簿牆(脫敏)、隱私旗標、抽獎券 |
| `notify-svc` | 系統中性提醒(email/簡訊)、兩檔位提醒 |
| `ledger-svc` | 公開帳本 |

## 二、使用者故事與驗收標準(可追溯性錨點)

**US-01(P1 新手)生活樣態配對**:作為第一次養貓的租屋族,我想用回答小問題的方式得到合拍的貓,而不是先被審查。
- `AC-01.1` 測驗一屏一題、每題可跳過、進度為正向句式
- `AC-01.2` 選「租屋」才觸發房東題,語氣為提醒非盤查
- `AC-01.3` 結果輸出 2–3 隻推薦+引用使用者答案的合拍理由
- `AC-01.4` 任何條件組合都不得出現「無符合結果」;受限條件輸出「目前最合拍」+誠實提醒+收藏輕承諾
- `AC-01.5` 全站(含錯誤訊息)禁用詞:審核/資格/申請條件/追蹤/檢查/監督/合格

**US-02(P2 共感)認識貓咪**:作為被個性打動的認養人,我要先讀到牠是誰,再看條件。
- `AC-02.1` 檔案頁個性故事置頂(第一人稱)
- `AC-02.2` 健康護照垂直時間軸;未完成項顯示「即將完成」非紅色警告
- `AC-02.3` 需求卡以貓為主詞,≤3 張,可展開「怎麼做」+採買參考
- `AC-02.4` 中途實名迷你檔案(暱稱、資歷、照顧哲學)

**US-03(全體)送出認養意向**:作為認養人,我想用預填的自我介紹草稿聯繫中途,確認後才送出。
- `AC-03.1` 草稿由測驗答案自動生成、可編輯
- `AC-03.2` 需明確按「送出」才送出;成功畫面告知預期回覆時間
- `AC-03.3` (變異組 B)草稿頁顯示除罪化文案與隱私說明
- `AC-03.4` 意向即時寫入該中途後台「想認識你家貓的人」清單,含測驗摘要卡
- `AC-03.5` 中途標記「不合適」→ 系統以轉介文案通知認養人並附替代推薦;不透露原因
- `AC-03.6` 意向摘要僅目標中途可見(其他中途/訪客不可見)

**US-04(全體+中途)媒合成功(承諾日)**:作為配對成功的雙方,我們要走完四階段,承諾後資料正確交接。
- `AC-04.1` 四階段狀態(相識→見面→試相處→承諾日)在認養人端與中途端一致
- `AC-04.2` 承諾確認後,貓即時自可認養列表與配對池下架
- `AC-04.3` 健康護照完整轉移至認養人帳戶(項目數、日期一致)
- `AC-04.4` 同胎成對送養的貓(兩隻不拆胎)必須成對承諾,不得單隻

**US-05(P3 隱私)曬貓回報**:作為重隱私的認養人,我要照片預設只給中途看、提醒像日曆通知、曬貓能抽獎。
- `AC-05.1` 每張照片預設「只給中途看」
- `AC-05.2` 切「公開」→ 相簿牆脫敏顯示(僅貓名+月齡,無認養人資訊);切回私密 → 牆上即時移除
- `AC-05.3` 逾期未回報 → `notify-svc` 以系統名義發中性提醒,不得出現中途個人名義(除非中途主動選「私訊關心」)
- `AC-05.4` 每回報一次得一張抽獎券,可累計、可自選獎池
- `AC-05.5` 匿名發問與帳戶/回報紀錄零關聯(後台不可反查)

**US-06(全體)無責退回**:作為養不下去的認養人,我要有一條不被追問的退回通道。
- `AC-06.1` 退回申請的原因欄位非必填,可空白送出
- `AC-06.2` 退回完成 → 貓回到原中途名下並重新上架;健康護照回轉
- `AC-06.3` 認養人帳戶不得因退回被標記不良/黑名單
- `AC-06.4` 該貓原公開時間軸自動封存(不再顯示於相簿牆)

**US-07(中途)減負後台**:作為一個人運作的中途,我要系統幫我做提醒與媒合整理。
- `AC-07.1` 久未曬貓清單提供兩檔位:「送出溫柔提醒(系統名義)」/「私訊關心(中途名義)」
- `AC-07.2` 配對訊息卡可標記聊聊看/再想想/不合適
- `AC-07.3` 健康護照更新後,檔案頁與(已認養時)認養人端同步

**US-08(平台)會話與一致性**:作為平台,匿名體驗要順、登入後資料要安全、A/B 分組要穩定。
- `AC-08.1` 測驗可匿名完成;送出意向需登入,登入後草稿與測驗答案不遺失
- `AC-08.2` 會話逾時後執行敏感操作 → 要求重新驗證,操作內容保留
- `AC-08.3` A/B 分組指派對同一訪客持久(跨會話一致)
- `AC-08.4` 登出後受保護頁面不得由瀏覽器快取洩漏
