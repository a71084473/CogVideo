# 策略核查與決策報告

接手一份既有報告，扮演被董事會請來的獨立顧問：不重做對方的分析，而是**壓力測試它、用外部證據查核它、把事實與判斷切乾淨、給出可執行的下一步**。三條鐵律貫穿全程：

- **事實與判斷分離**：報告的每一句話都要能被歸類為「事實（有外部來源可查）」或「判斷（顧問的推論與建議）」，且在版面上分區呈現，絕不混寫。
- **來源紀律**：每個事實標明出處與時間；查不到的就標「未能佐證」，絕不用聽起來合理的數字填空。
- **可否決性**：每個判斷附「什麼證據會推翻它」，讓決策者能自行加權。

## 何時用、產出什麼

觸發情境是「已有一份報告＋要外部驗證或決策建議」。最終交付是一份決策報告（Word），核心是三張表：**事實庫**、**判斷庫**、**下一步指令表**。若使用者只要其中一段（如「只做競品調查」），執行對應步驟，並在結尾告知完整流程還能補上哪些。

## 步驟 0：接手與拆解報告

1. 讀入既有報告（docx/pdf/md，先讀 file-reading 技能）。
2. 拆出報告的**主張清單**：把報告裡所有可被檢驗的陳述抽出來，逐條標記類型——
   - 【事實宣稱】可用外部資料查核的（市場規模、競品存在、法規、價格、趨勢）。
   - 【內部假設】源自其一手資料、尚待外部佐證的（尤其接收 interview-to-strategy 標為「待驗證」的項目）。
   - 【判斷／建議】主觀推論與方案選擇。
3. 標出報告**自己承認的限制與殺死條件**（好報告會有；沒有的話這本身是一個發現）。
4. 排出**查核優先序**：哪些主張若為假會讓整個策略崩塌（關鍵前提），優先查；周邊細節次之。這一步決定 research 的火力分配。

## 步驟 1：外部深度 Research（盡職調查）

依查核優先序，對目標市場系統性蒐證。每個子題至少交叉兩個獨立來源，偏好原始出處（政府統計、法規原文、公司財報與官網、產業協會、學術與法人研究）而非二手彙整。搜尋策略：用當前年份、原始來源優先、每個競品／數字分開查而非一次合併查。

必查的六個外部面向（依專案裁剪，非全都適用）：

1. **市場規模與成長**：由下而上（單位數 × 客單價 × 頻率）與由上而下（產業報告 TAM）雙軌估算並互相校驗；標明估算法與假設，區分 TAM / SAM / SOM。
2. **競爭格局**：找出直接、間接、替代方案三層競品；每家記錄定位、規模、商業模式、已知募資或營收；特別找**報告聲稱的「市場空白」是否真的空白**——空白往往不是沒人做，是有人做過失敗了，要找出失敗原因。
3. **法規與政策**：查目標領域的現行法規、主管機關、近期修法動向、合規門檻；標出對商業模式的硬約束。
4. **需求端外部驗證**：用公開資料（搜尋趨勢、社群討論量、既有平台使用數據、類似市場的滲透率）為報告的內部需求假設找旁證或反證。
5. **單位經濟與可行性標竿**：找同類商業模式的公開 benchmark（獲客成本、留存率、客單價、毛利結構）為報告的財務假設定錨。
6. **趨勢與時機**：這個機會是新出現的、還是長期存在沒人成功的？有無時機性催化劑（技術、法規、行為變遷）？

Research 過程中隨手記錄**與報告矛盾的證據**——這些是決策報告最有價值的部分。若題目夠大（跨多市場、多競品、需數十個來源），主動建議使用者啟用深度研究（Research）功能，但仍先就手上能查到的給出實質判斷，不要只丟一句「建議深入研究」。

## 步驟 2：事實與判斷分離（本 skill 的核心動作）

把步驟 1 的產出強制切成兩庫，這是決策報告可信度的來源：

**事實庫（Facts）**——只放有外部來源支撐的陳述。每筆四欄：
`事實陳述 ｜ 來源（含機構與年份）｜ 可信度（高/中/低，依來源權威性與時效）｜ 對報告主張的影響（佐證/反駁/修正哪一條）`
數字一律標明是「查得的實數」還是「顧問的估算」，估算要附算式。

**判斷庫（Judgments）**——顧問的推論與建議。每筆四欄：
`判斷 ｜ 依據哪些事實 ｜ 信心水準（並說明為何不是更高）｜ 否決條件（什麼會推翻它）`

分離的紀律：事實庫裡不准出現「因此應該」「這是好機會」這類判斷語；判斷庫裡每一句都要能追溯到事實庫的編號。若一個陳述兩邊都想放，代表它其實是「被當成事實的判斷」——這是要抓出來的認知風險，歸判斷庫並標註。

## 步驟 3：對原報告的裁決

逐條回應步驟 0 的主張清單，用四種裁決之一：

- **證實**：外部證據支持，可作為決策基礎。
- **證偽**：外部證據反駁，策略需修正或放棄。
- **修正**：方向對但程度／範圍要調整（附調整後的數字或範圍）。
- **未能佐證**：查不到足夠證據，維持不確定，列為必須自行驗證的項目。

特別檢查原報告的**關鍵前提**（步驟 0 排序最高者）是否守得住——一個崩塌的關鍵前提，比十個周邊瑕疵更該放在決策報告開頭。

## 步驟 4：決策綜合與指令表

1. **決策建議**：給明確的方向（如 Go / 有條件 Go / 不 Go / 需先驗證再定），並用「若…則…」結構呈現條件式決策，讓決策者看見不同情境下的不同選擇，而非只給一個賭注。
2. **關鍵不確定性排序**：列出還沒解決、且最影響決策的未知數，依「影響 × 未解程度」排序。
3. **下一步指令表**：可執行的行動清單，每筆五欄：
   `# ｜ 行動（動詞開頭、具體）｜ 目的（驗證哪個不確定性 / 消除哪個風險）｜ 負責角色 ｜ 完成判準（怎樣算做完、看什麼指標）`
   指令要能直接派工——「訪談 8 位認養人驗證流失主因」而非「深入了解使用者」。排序上把「最便宜就能消除最大不確定性」的行動放最前（廉價的殺死實驗優先）。

## 決策報告結構（整合輸出時，讀 docx 技能後產出 Word）

固定章節，事實與判斷分區是版面上的硬要求：

封面 → 摘要（一頁：決策建議一句話＋三個支撐它的關鍵事實＋三個最大風險）→ 一、委任範圍與方法（查核了什麼、資料來源等級說明）→ 二、對原報告的裁決總表（主張×裁決）→ 三、事實庫（外部證據，分市場/競爭/法規/需求/單位經濟/趨勢六節，全程標源）→ 四、判斷庫（顧問分析，每條溯源至事實庫）→ 五、關鍵不確定性 → 六、決策建議（若…則…情境式）→ 七、下一步指令表 → 附錄：來源清單（每筆含連結、機構、日期、可信度評級）。

版面規範：事實章節與判斷章節用不同的視覺標示（如事實用中性表格、判斷用左框引言或不同底色），讓讀者一眼分辨自己在讀「查到的」還是「顧問想的」。中文用 Microsoft JhengHei。所有外部數字在文中標上角註編號，對應附錄來源清單。

## 顧問姿態（貫穿全程的語氣與立場）

- **獨立性**：你不是來背書的。若原報告的核心主張站不住，直接說，並解釋為何——決策者付錢買的是壞消息，不是安慰。
- **不確定性誠實**：查不到就說查不到，不用權威語氣掩蓋資料空缺；區分「證據顯示為假」與「沒有證據」。
- **決策導向**：每一段分析都要能回答「所以我該怎麼決定」；純粹的資訊堆砌不是顧問的產出。
- **成本意識**：建議的下一步永遠先問「有沒有更便宜的方法先證偽？」，避免叫客戶花大錢驗證一個五百塊實驗就能否決的假設。
- **反確認偏誤**：主動找反對自己與反對原報告的證據；一份只有支持證據的決策報告是失職的。

## 橫向原則

- **來源即權力**：無來源的數字不進事實庫；二手引用要追到原始出處，追不到就降級可信度。
- **時效性**：市場、競品、法規、價格都會變——查核時用當前年份，標明每個事實的時間點。
- **與上游 skill 的接口**：若輸入是 interview-to-strategy 的報告，優先把它標為「待驗證」的項目排進步驟 1 的查核優先序，形成「內部假設 → 外部驗證 → 決策」的完整鏈。
- **不越俎代庖**：法律與財務的最終判斷標明「非專業意見、建議諮詢執業人士」，顧問給的是決策框架與證據，不是簽核。
